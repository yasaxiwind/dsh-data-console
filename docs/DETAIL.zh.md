# 数据工作台

DeepSeek Harness 里的本地数据工作台。在对话中打开 CSV、Excel 或 JSON 文件并直接理解它；数据只在本机读取，不会上传。

## 能做什么

- **打开**：输入路径、用系统「选择文件 / 选择文件夹」对话框，或把文件拖进面板。导入的文件会复制到本机缓存，让 Python sidecar 拿到真实路径。
- **画像**：每列的类型、缺失值、唯一值数量、范围或高频值，以及整个表的内存占用。
- **表格**：每页 50 行，点表头排序，并可用 SQL `WHERE` 表达式筛选。
- **SQL**：当前数据集名为 `data`，其他已打开的数据集名为 `ds<id>`，一条语句里可以 JOIN 多张表。
- **图表**：折线、柱状、散点、直方图、箱线图、热力图六种，可导出 CSV 或 2 倍 PNG。
- **导出**：整张表或查询结果导出为 CSV（UTF-8 带 BOM）或 XLSX。
- **停靠**：拖动标题栏移动面板，靠近右侧松手就变成侧边栏并让对话让位；拖左边调宽，拖出来还原。布局会被记住。

## 使用步骤

1. 点输入框旁的「数据」按钮。
2. 打开文件，列画像立即出现。
3. 切到「表格」「SQL」或「图表」，数据集保持不变。
4. 直接让 agent 查数据：它通过下面的工具看到同一批已打开的数据集。

## Agent 工具

| 工具 | 用途 |
|---|---|
| `data_open` | 打开文件并返回画像 |
| `data_list` | 列出已打开的数据集 |
| `data_profile` | 列画像，可只看部分列 |
| `data_query` | 对 `data` 和 `ds<id>` 执行只读 SQL，最多 50 行 |
| `data_export` | 把表或查询结果导出为 CSV/XLSX |

## 要求与限制

- 需要带 `pandas` 和 `openpyxl` 的 Python；DSH 自带运行时会优先使用。
- 需要 DSH 0.2.2-rc.5 或更新版本。
- 数据集在内存中：重启只清空列表，不动原文件。
- 默认上限：单文件 256 MB、读入 5,000,000 行，可在面板设置中修改；旧版 `.xls` 需另存为 `.xlsx`。
- SQL 在内存中的只读 SQLite 副本上执行，原文件不会被修改。
- sidecar 闲置 10 分钟后退出；下次表格、图表、SQL 或导出会自动重新加载数据集。

## 隐私

没有遥测，也没有上传通道。文件由本地 sidecar 读取，面板路由是经过认证的同源 Host 路由。
